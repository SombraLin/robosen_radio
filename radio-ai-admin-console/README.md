# RADIO AI Admin Console (React 管理后台前端)

本工程是 RADIO AI 玩偶互动频道平台的**独立 React 19 + Vite Web 管理控制台前端**。

## 📦 页面与视图功能

- **频道全览 (Channels Overview)**：玩偶卡片管理、频道生命周期控制、Prompt 人设编辑、动态声音测试。
- **频道排播工作室 (Channel Studio)**：内容节点编排、TTS 语音节点实时生成、物理音频组装与资源固化 (Freeze Manifest)。
- **音频资产库 (Audio Assets)**：统一物理音频文件与在线 TTS 音频文件管理。
- **自动化控制台 (Automation)**：ZAKER 抓取策略配置、手动触发与执行日志盘点。
- **设备模拟器 (Device Simulator)**：模拟智能硬件播放器，演练打断对话与多玩偶剧场连线。

## 🚀 启动说明

### 安装依赖

```bash
npm install
```

### 本地开发启动 (端口 3000)

```bash
npm run dev
```

### 构建打包

```bash
npm run build
```
